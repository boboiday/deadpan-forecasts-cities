A deadpan TV weather forecast for Varnmouth, a city that does not exist: 9°C, north-easterly winds of 52 km/h, and rain falling upwards over the harbour — delivered with the straight face of a real broadcast, right down to the fishermen anchoring their boats to the sky.

## Run it

```sh
node main.ts
```

This prints the forecast to stdout and writes it to `/output/entry.txt` (147 characters, valid UTF-8).
